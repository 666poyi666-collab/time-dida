## 主要变化

- 计时仪表从五套扩展到九套：新增滚筒计数器（里程表滚筒逐位进位）、指针表圈（60 刻度 + 秒针擒纵步进 + 中央读数）、游标标尺（固定游标线下滑动秒刻度带）、制图描线（描边空心数字 + 制图网格与尺寸标注）；设置页 3×3 实时预览。
- 手表端（OWW221）专项：AMOLED 防烧屏——强制深色、纯黑画布、待机读数压暗、4 分钟 1px 位移；主视图改为「状态/读数/任务/操作」四行铺满；界面字体改系统字族省去数 MB Web 字体，任务页打开时暂停秒针刷新。
- 时间之带材质升级：专注实体获得以 0.5s 世界格为键的确定性羽化轮廓、齿端浮尘与内部颗粒；冻结语义保持逐像素稳定。
- 死命令落地：AGENTS.md 固化每轮三端（+手表）真实安装门禁；废除五版本检查点，每次改动即推送 GitHub。
