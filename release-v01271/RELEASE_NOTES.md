# FocusLink v0.12.71

- 发布类型：正式版
- 验证状态：构建与四端安装待完成
- 对应源码：`<SOURCE_COMMIT>`

## 主要变化

- 手机和平板采用新的「工业时间仪器」界面：深墨设备框架、暖白连续工作面与翡翠状态校准线贯穿专注、任务、统计和设置。
- 手机首屏优先显示主计时读数、任务输入和 112px 时间之带，主操作条固定在 68px 底部导航之上。
- 华为平板 640 CSS-pixel 竖屏使用全宽计时主区，多端上下文移到下方；760px 起才展开双栏。
- 统计页改为深墨结论舞台，设置与任务页使用同一连续仪器语法；亮暗主题分别校准，不再使用主读数径向 glow。
- Windows 实时控制、任务快照与 Sync v2 统一使用 `fl2` 凭据绑定的设备 ID，修复“开始专注”返回 HTTP 403；空闲云端凭据失效或网络失败时，本地计时仍可立即开始并留下明确诊断。
- 设置页九种计时仪表预览全部适配固定舞台，指针表圈、游标标尺和制图描线不再显示不全；桌面时间之带删除所有状态可回落的旧毛边/分节绘制路径。

## 保留能力

- Windows 两态 mini 窗口未改。
- 华为 `huawei-live-capsule`、小米系统通知路径和 OPPO 手表 renderer 未改。
- FocusLink 云端实时控制、离线本机会话、任务快照与已结束账本协议未改。

## 验证摘要

- 自动化、Windows 安装、Android APK 与四端实装结果将在正式构建后填写。

## 升级提示

- Windows 使用安装版覆盖安装；Android 手机、平板与手表使用同一个 `0.12.71 / 1271` APK 覆盖安装并保留应用数据。

## 已知限制

- 手机、平板和 OPPO 手表共用同一响应式 Android APK；当前仍使用与既有设备一致的调试签名。
- 移动端只控制 FocusLink 云端活动会话；滴答清单与番茄 To-do 的第三方投递仍由桌面端执行并确认。
